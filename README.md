## 数据集概述

本数据集专注于**变电站场景下电力设备的视觉检测与分类**，服务于电力巡检、设备状态评估及运维管理。数据涵盖五类变电站核心设备部件，适配无人机巡检、机器人巡检及固定监控的自动化识别应用。

## 数据三要素解析

**类别与设备覆盖**
*   数据集定义 **5** 类变电站设备部件，类别以拼音缩写标注，覆盖互感器、避雷器、绝缘子等常见一次设备部件。
*   具体类别含义需根据标注文件确认，建议使用前先核对 `data.yaml` 中的类别名称定义。
*   类别设置聚焦于变电站常见设备部件，具有较强的巡检应用导向。

**数据规模与版本**
*   图像总量约 **1171** 张，规模适中，能支撑多类别设备检测模型的训练。
*   数据集有 **1** 个版本，数据已整理完毕，可直接使用。
*   图像涵盖变电站不同光照、拍摄角度下的设备影像。

**格式与结构**
*   采用通用 **YOLO 格式**（txt），每张图像对应一个同名标签文件，包含类别 ID 与归一化边界框坐标，可直接接入 YOLOv5、YOLOv8 等主流检测框架。
*   图像与标签一一对应，数据结构规范，便于进行训练/验证集划分与预处理集成。

## 知识普及：变电站设备检测的技术要点

*   **部件相似性**：变电站部分设备部件在外观上相似（如各类绝缘子），模型需依赖安装位置、尺寸比例等上下文信息进行区分。
*   **背景复杂性**：变电站场景中设备密集、结构交错，部件之间可能相互遮挡，模型需具备较强的特征提取能力。
*   **光照与天气影响**：户外变电站受光照、天气影响显著，建议训练时加入亮度、对比度增强与雨雾模拟。
*   **小目标检测**：部分设备部件（如连接件、销钉）尺寸较小，需采用高分辨率输入或多尺度特征融合策略。
*   **应用闭环**：检测结果可结合设备台账与缺陷识别模型，构建变电站智能巡检与运维决策系统。

## 快速开始（代码示例）

配置文件 `data.yaml` 示例（需根据实际类别含义填写）：
```yaml
train: ./dataset/images/train
val: ./dataset/images/val
nc: 5
names: ['hxq_bs', 'hxq_zc', 'jsxx', 'sly', 'xgw']
```

启动 YOLOv8 训练：
```python
from ultralytics import YOLO

model = YOLO('yolov8m.pt')
model.train(
    data='data.yaml',
    epochs=100,
    imgsz=640,
    batch=16,
    device=0
)
```
